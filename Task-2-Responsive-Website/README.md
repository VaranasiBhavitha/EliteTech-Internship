# Responsive Student Productivity Dashboard

## Internship Task 2

This project is a responsive student productivity dashboard
developed using HTML, CSS, and JavaScript.

## Objective

The objective of this task is to design a webpage that adapts
to different screen sizes including desktop, tablet, and mobile.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive navigation bar
- Mobile hamburger menu
- Student dashboard
- Study statistics
- Daily task checklist
- Study resources section
- Interactive task completion
- Smooth scrolling
- Responsive desktop, tablet, and mobile layouts

## Responsive Design

CSS media queries are used to adapt the layout for:

- Desktop
- Tablet
- Mobile

## Project Structure

Task-2-Responsive-Website/

├── index.html  
├── style.css  
├── script.js  
└── README.md

## How to Run

1. Download or clone the repository.
2. Open the Task-2-Responsive-Website folder.
3. Open index.html in a web browser.
