# Task 3 – Mobile App Redesign

## Objective
Redesign a popular mobile app UI/UX to address a specific user pain point.

## App Concept
Payment App Redesign

## Problem / Pain Point
Users need quick access to common payment actions without unnecessary navigation.

## Proposed Solution
The redesigned interface prioritizes frequently used payment actions such as Send Money and Scan & Pay.

## Key Improvements
- Easy access to Send Money
- Dedicated Scan & Pay option
- Simple contact selection
- Clear amount entry screen
- Separate payment review screen
- Clear payment success confirmation
- Simple and consistent user flow

## User Flow

Home
↓
Send Money
↓
Choose Contact
↓
Enter Amount
↓
Review Payment
↓
Payment Successful
